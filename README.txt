Para GitHub Pages:
1. Sube index.html y sw.js a la misma carpeta (idealmente la raíz del repositorio).
2. Si tu página actual usa otro nombre, puedes renombrar index.html como necesites, pero sw.js debe quedar junto a la página.
3. Abre la página una vez con Internet para que el navegador guarde los recursos.
4. Luego puede continuar funcionando sin señal para las funciones locales.

V75 incluye:
- Modo local/sin señal con indicador de estado.
- Guardado local de los datos existentes.
- Cámara de código de barras más compacta.
- Miniatura pequeña del producto después del escaneo.
- Service Worker para conservar la aplicación y recursos después de la primera carga online.
